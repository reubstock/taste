# TASTE™

The website for an agency that doesn't exist yet.

AI gives the permutations. We give the taste.

## Routes

- `/` — Home
- `/work` — Selected work
- `/work/[slug]` — Case studies (Solstice, Heron, Mainline, Public Library)
- `/manifesto` — Five things we believe
- `/offers` — Launch Mode · Always-On · Embed
- `/studio` — The bench + the agent stack
- `/brief` — Brief us

## Stack

- Next.js 16 (App Router, Turbopack)
- TypeScript, no Tailwind
- `Instrument Serif` / `Inter` / `JetBrains Mono` via `next/font`

## Run it

```bash
npm install
npm run dev
```
